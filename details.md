# 📝 Todo List App

A responsive, fast, and minimalist Todo List web application built using **React**, **Vite**, and **Tailwind CSS**.

---

## 🚀 Features

- ➕ Add new tasks seamlessly
- ✅ Mark tasks as completed / active
- 🗑️ Delete unwanted tasks
- 📱 Fully responsive layout across mobile and desktop
- ⚡ Fast performance powered by Vite

---

## 🛠️ Tech Stack

- **Framework:** React
- **Build Tool:** Vite
- **Styling:** Tailwind CSS
